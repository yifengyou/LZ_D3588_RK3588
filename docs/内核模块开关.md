* CONFIG_POSIX_MQUEUE

```text
报错信息 error mounting "mqueue" to rootfs at "/dev/mqueue": ... no such device 
```

Docker 在启动容器时，试图挂载 POSIX 消息队列（POSIX Message Queues）文件系统到容器的 /dev/mqueue 目录，内核不支持这个功能



* CONFIG_CGROUP_BPF

Docker 在尝试设置容器的 cgroup（控制组）配置时，需要调用 BPF (Berkeley Packet Filter) 相关的功能，但你的系统内核没有实现这个功能，因为它在编译时没有开启相应的选项。
